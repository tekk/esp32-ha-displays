# Guition JC3636F118

基于 JC3636K718（太极派）硬件，使用新的引脚定义（PINCONFIG.H）适配的固件。

## 引脚定义

| 功能 | 引脚 |
| --- | --- |
| SDMMC SCK / CMD / D0-D3 | GPIO24 / 25 / 20 / 21 / 22 / 23 |
| 触摸 I2C (I2C_NUM_0) SDA / SCL / RST / INT | GPIO11 / 10 / 9 / 8 |
| LCD QSPI SCL / CS / D0-D3 / RST / TE / BLK | GPIO12 / 13 / 14-17 / 18 / 19 / 5 |
| 功放 PA_CTRL | GPIO50 |
| I2S BCK / WS / DO | GPIO53 / 51 / 52 |
| MIC SCK / DATA | GPIO39 / 37 |
| 电池 BAT_DAC | GPIO55 |
| 旋钮 KNOB_A / KNOB_B | GPIO6 / 7 |

显示屏分辨率 360x360，16bit，使用 ST77916 驱动（QSPI 接口）。触摸使用 CST816S。

## 编译

```bash
idf.py set-target esp32s31
idf.py menuconfig
# Xiaozhi Assistant -> Board Type -> Guition JC3636F118
idf.py build
```

或使用构建脚本：

```bash
python3 scripts/build.py guition-jc3636f118 --name guition-jc3636f118
```

> 注意：`AUDIO_MUTE_PIN` 已映射为 `PIN_PA_CTRL`(GPIO50)，默认高电平使能功放。
> 若实际硬件为低电平有效，请将 `config.h` 中 `InitializeMute()` 的输出电平改为 0。
