esp_hosted较高版本时,esp32c6会在重启之后自动重连上次的WiFi,可能会导致连接wifi失败或者扫描不到wifi.

如果发现设备扫描不到WiFi或者一直连接wifi时请修改78__esp-wifi-connect/wifi_configuration_ap.cc

```makefile
    ESP_ERROR_CHECK(esp_timer_create(&timer_args, &scan_timer_));	//未修改的108行
	//新增部分
    esp_timer_start_once(scan_timer_, 10 * 1000000);	//立刻调用一次定时器，避免调用扫描函数时esp32c6正处于连接wifi的状态，不进行扫描
```

```makefile
	is_connecting_ = true;
    esp_wifi_scan_stop();		//未修改的688行
	//新增部分
    auto ret = esp_wifi_disconnect();	//断开wifi连接
    vTaskDelay(pdMS_TO_TICKS(500));		//延时，确保接收到WIFI_FAIL_BIT
    if(ret != ESP_OK)
    {
        ESP_LOGI(TAG,"Failed to disconnect to wifi %s",esp_err_to_name(ret));
    }
```

如果烧录完成之后出现屏幕一直不亮的情况请查看串口输出，是否有如下报错
