ESP32-2432S024R

Guition · ESP32 development board display

ESP32-2432S024R is a 2.4" 240x320 TN Resistive touch ESP32 display board by Guition based on the ESP32 with 4MB flash, - PSRAM.

Open the interactive page (gallery, files, archives) →

Features, ports & interfaces

  • SPI display
  • Resistive touch
  • 4 MB flash
  • microSD (TF) card slot
  • Wi-Fi 4 (802.11 b/g/n, 2.4 GHz) – version from the ESP32 datasheet
  • Bluetooth 4.2 BR/EDR (Classic) + BLE – version from the ESP32 datasheet
  • Serial port (UART)
  • GPIO / IO port expansion
  • DHT11 temperature / humidity sensor port
  • Speaker interface
  • Lithium battery support (charging)
