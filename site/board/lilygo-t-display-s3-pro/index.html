T-Display S3 Pro

LilyGO · LilyGO T-Display S3 Pro – ESP32-S3 2.33" 222×480 touch IPS

T-Display S3 Pro is a 2.33" 222x480 IPS Capacitive touch ESP32 display board by LilyGO based on the ESP32-S3 with 16MB flash, 8MB PSRAM.

Open the interactive page (gallery, files, archives) →

Features, ports & interfaces

  • SPI display
  • Capacitive touch
  • 8 MB PSRAM
  • 16 MB flash
  • Wi-Fi 4 (802.11 b/g/n, 2.4 GHz) – version from the ESP32-S3 datasheet
  • Bluetooth 5 (LE) – version from the ESP32-S3 datasheet
  • Light / proximity sensor: LTR-553ALS-01 light + proximity sensor
  • Buttons: Boot + Reset + IO12 + IO16
