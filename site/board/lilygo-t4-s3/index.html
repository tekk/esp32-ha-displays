T4 S3

LilyGO · LilyGO T4 S3 – ESP32-S3 2.41" 450×600 QSPI AMOLED touch

T4 S3 is a 2.41" 450x600 AMOLED ESP32 display board by LilyGO based on the ESP32-S3 with 16MB flash, 8MB PSRAM.

Open the interactive page (gallery, files, archives) →

Features, ports & interfaces

  • QSPI display
  • 8 MB PSRAM
  • 16 MB flash
  • microSD (TF) card slot
  • Wi-Fi 4 (802.11 b/g/n, 2.4 GHz) – version from the ESP32-S3 datasheet
  • Bluetooth 5 (LE) – version from the ESP32-S3 datasheet
  • Buttons: Boot + Reset
