ESP32-2424S012C_I_Y(B)

Guition · 1.28 inch ESP32 display module

ESP32-2424S012C_I_Y(B) is an 1.28" 240x240 IPS Capacitive touch ESP32 display board by Guition based on the ESP32-C3 with 4MB flash, - PSRAM.

Open the interactive page (gallery, files, archives) →

Features, ports & interfaces

  • SPI display
  • Capacitive touch
  • 4 MB flash
  • Wi-Fi 4 (802.11 b/g/n, 2.4 GHz) – version from the ESP32-C3 datasheet
  • Bluetooth 5 (LE) – version from the ESP32-C3 datasheet
  • Serial port (UART)
  • Speaker interface
  • Lithium battery interface (charging)
  • Enclosure / shell
