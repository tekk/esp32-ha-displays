JC3636W518C_I_Y

Guition · 1.8 inch ESP32S3 display module

JC3636W518C_I_Y is an 1.8" 360x360 IPS Capacitive touch ESP32 display board by Guition based on the ESP32-S3 with 16MB flash, 8MB PSRAM.

Open the interactive page (gallery, files, archives) →

Features, ports & interfaces

  • QSPI display
  • Capacitive touch (CST816)
  • 8 MB PSRAM
  • 16 MB flash
  • microSD (TF) card slot
  • Wi-Fi 4 (802.11 b/g/n, 2.4 GHz) – version from the ESP32-S3 datasheet
  • Bluetooth 5 (LE) – version from the ESP32-S3 datasheet
  • Speaker interface
  • Enclosure / shell
