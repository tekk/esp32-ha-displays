Basic v2.7

M5Stack · M5Stack Basic v2.7 – ESP32 2.0" IPS controller with 3 buttons

Basic v2.7 is a 2.0" 320x240 IPS ESP32 display board by M5Stack based on the ESP32 with 16MB flash.

Open the interactive page (gallery, files, archives) →

Features, ports & interfaces

  • SPI display
  • 16 MB flash
  • microSD (TF) card slot
  • Wi-Fi 4 (802.11 b/g/n, 2.4 GHz) – version from the ESP32 datasheet
  • Bluetooth 4.2 BR/EDR (Classic) + BLE – version from the ESP32 datasheet
  • USB-C
  • I2C port
  • Grove port: HY2.0-4P (I2C)
  • Speaker: 1 W speaker
  • Battery: 110 mAh @ 3.7 V
  • Buttons: 3x physical buttons
