T-Dongle S3

LilyGO · LilyGO T-Dongle S3 – ESP32-S3 USB dongle with 0.96" IPS and TF slot

T-Dongle S3 is a 0.96" 80x160 IPS ESP32 display board by LilyGO based on the ESP32-S3 with 16MB flash.

Open the interactive page (gallery, files, archives) →

Features, ports & interfaces

  • SPI display
  • 16 MB flash
  • microSD (TF) card slot
  • Wi-Fi 4 (802.11 b/g/n, 2.4 GHz) – version from the ESP32-S3 datasheet
  • Bluetooth 5 (LE) – version from the ESP32-S3 datasheet
  • Buttons: Boot button
